    Atlas: conventions/

    TLDR

    Memory conventions are the shared vocabulary for provenance, retrieval scope, audiences, and metadata. They prevent every consumer from inventing a different meaning for the same stored thought. The rules favor explicit allowlists, traceable source classes, and audience boundaries. Builders use them before importing data or writing recall code so a technically successful query cannot silently violate the intended memory contract.

    What this page covers

    This page maps the adopted convention document. It is design authority for how memory records are classified and requested, while schemas and code implement that authority. Changes require corresponding verifier, migration, and consumer review.

    File entries

    conventions/memory-conventions.md

    authority
    What it is. The adopted memory vocabulary and scoping authority for every producer and consumer.
    What it contains. Source types, provenance classes, metadata keys, retrieval allowlists, audience scoping, and the distinction between storage visibility and who may receive recalled material.
    Who reads it and when. Schema authors, ingestion builders, recall services, and reviewers read it before handling memory.
    How to verify or reproduce it. Map every source type to one provenance class, validate required metadata, test allowlists with denied cases, and confirm audience boundaries survive ingestion and recall. Review status language against the implementation ledger so prepared, dark, partial, pending, and live states remain distinct. Treat any contradiction with higher-authority design as a decision-log issue, not permission to choose whichever instruction is easier. A clean reproduction records commands and evidence, preserves failed checks as failures, and leaves human-owned gates untouched. Keep credentials, runtime coordinates, protected identity material, and private human details outside every review artifact.
    Related concepts. See memory and provenance, segmentation, and governance.
