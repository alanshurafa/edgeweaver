# Adversarial review of Revision 2 (Fable pass) — 2026-07-03

*Third pass in the plan's own witnessed-revision lineage: Claude reviewer → Codex composer →
fresh-context Fable adversary attacking the changes. Findings below were integrated into
Revision 3 of PLAN.md. Verdicts: 13 of 21 bounce resolutions stand (list at bottom); 8 weak
resolutions amended; 2 load-bearing losses restored; 6 fresh blind spots addressed.*

## A. Wrong or weak resolutions (all AMENDED in Rev 3)

- **A1 — §8 ablation test unrunnable/confounded.** A parallel control-Edgeweaver means double
  infra, double cost, and one person sustaining two comparable relationships; the variants'
  memories diverge within days (nothing controlled by day 90); Alan is a single, unblinded,
  pre-committed judge and the PM version self-identifies by citing distinctions. → Replaced
  with masked-context A/B on the same being: frozen scenario set run with PM context present
  vs masked, responses shuffled, rated blind, ≥1 rater besides Alan, plus a longitudinal
  locus-of-control trend. Residual confound (memories are PM-shaped) stated plainly.
- **A2 — §2.4 four-feelings signals lack substrate.** Anger's "boundary overrides" needs a
  boundary registry + override classifier that were never scheduled — and as defined it counts
  Alan's legitimate gate declines as overrides, rising mechanically the better governance works.
  Sadness needs a commitment tracker that doesn't exist. Joy is 0/0 until experiments exist.
  Only fear is computable today. And multi-day windows measure what PM calls *emotions/mood*,
  not feelings (<~3 min, present-moment) — contradicting the plan's own corpus. → Prerequisites
  scheduled (boundary registry, commitment tracker seeded from nightly intentions); governance
  outcomes excluded from anger; joy cold-start fallback (completed-loop rate); two timescales
  named honestly (per-wake feeling readings vs mood/emotion tier).
- **A3 — §5 probe battery measures memory + one rater's drift, not identity.** Probe responses
  get written as episodes, so run N retrieves run N-1 (self-copying); Alan rates unblinded with
  a drifting baseline; no re-anchoring after accepted initiations; blanket rejection of
  automated metrics contradicts the survey's drift-tripwire recommendation. → Frozen-snapshot
  quarantine with write-back off; shuffled blind rating; formal baseline re-anchor per merged
  initiation (delta in LINEAGE.md); automated distributional drift as tripwire that escalates
  to humans; second rater by first initiation.
- **A4 — §2.3 "fire on surprise" had no mechanism; cost numbers deleted rather than adopted.**
  Surprise requires logged predictions and something awake to check them; the theory-of-Alan
  existed only as a steal-table row. Night loop cost (~$1–7/night) was never estimated. →
  Surprise operationalized: night loop writes explicit expectations; heartbeat scores new
  observations against them; theory-of-Alan scheduled as an artifact; crude cost table added
  to §10.2.
- **A5 — §2.5 idempotency fixed crash-resume, not garbage-compounding.** A coherent-but-wrong
  reading still flows into autobiography and tomorrow's intention ungated; doc was split on
  incremental vs regenerated autobiography. → Nightly writes declared provisional; weekly
  index rebuild-from-atoms named as the compounding firewall; night-loop outputs added to the
  weekly human spot-check.
- **A6 — §6 projection queue = unspecified write path into episodic memory.** Third-party
  surfaces generating "episode summaries" is a trusted-sounding injection channel. → Staging
  status, named night-loop ingestion step, same trust class as untrusted channel content;
  third-party surfaces read-only + queue.
- **A7 — §3 retrieval scoping covered one query path of several.** Entity-wiki synthesis,
  autobiography synthesis, and generic semantic-search tools would still absorb library text;
  blocklist phrasing leaks by default. → Inverted to per-consumer source_type allowlists;
  library types excluded by default from every derived-memory synthesizer.
- **A8 — §0 locus-of-control rubric rewards confabulated self-blame.** Scoring "externalizing"
  bottom pressures the model to invent causal roles in failures it didn't cause — "pretend" in
  PM terms, and a violation of the honesty clause. → Top score requires accurate causal
  attribution AND real own-role AND a preventive change; fabricated self-causation is a scored
  failure mode.

## C. Fresh blind spots (ADDED in Rev 3)

- **C1 — every control loop terminates in one unblinded human, and the being drafts every PR.**
  Alan is memory confirmer, initiation reviewer, probe rater, ablation judge, spot-checker,
  diary auditor, and primary attachment figure; the plan's own corpus says one person is the
  subvertible unit (the 3Cell's reason to exist). Gate artifacts living in the soulfile repo
  would let the agent author proposed changes to its own evaluator. → 3Cell quote restored;
  second witness pulled forward to Phase 5 (no solo-witnessed merges after the first
  initiation); probe battery, rubric, and autonomy-tier definitions moved to a separate
  Alan-only repo outside the PR surface; cooling-off period on constitution hard-boundary PRs.
- **C2 — night loop writes fiction and judgments into the table ordinary recall reads.**
  Dreams/reflections/feeling_readings are thoughts; a dream inventing a plausible event becomes
  retrievable as if experienced — self-poisoning with no attacker. → Recall returns provenance
  class per hit; `dream` excluded from factual recall by default; derived types labeled
  interpretations, never events.
- **C3 — pre-birth memories create a third-party disclosure problem.** Years of Alan's private
  ChatGPT disclosures become queryable substrate for a being that will talk to other people;
  `visibility` only governed Edgeweaver's privacy from Alan, nothing governed Alan's privacy
  from third parties. Also: CC BY-SA does not compel publishing the constitution — publication
  is a deliberate act. → Audience/disclosure model: recall scope keyed to interlocutor
  (alan / known-other / public); `era: pre_birth` defaults Alan-only until reviewed; Appendix A
  reworded (deliberate, redacted publication).
- **C4 — no degraded-mode policy for OB1 outages; PITR is a paid add-on.** Under "anything not
  written to OB1 didn't happen," an outage un-happens experience. → Local write-ahead episode
  buffer with replay; on read failure the being states degraded memory instead of confabulating;
  verify Supabase tier or make scheduled dumps + tested restores the real mechanism.
- **C5 — "no public port" is true and beside the point.** Bot tokens are a remote attack
  surface; nothing bound "Alan" to authenticated sender IDs while Alan-over-channel is the
  trust anchor for confirmations. → Pin Alan's channel user IDs; out-of-band/signed
  confirmation for tier changes; note no-public-port ≠ no remote surface.
- **C6 — cross-reference misalignments.** EDGE-MAP.md ships at birth but `edge` starts Phase 5
  (→ seed manually at First Boot); importance recalibration promised in App B but missing from
  the §2.5 step list (→ added); App-B conventions must be a Phase 0b entry criterion since 0b
  can precede Phase 1 (→ stated).
